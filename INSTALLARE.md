# Instalare si rulare

Proiectul Sidera este o aplicatie Electron + React + TypeScript. Dependentele nu sunt definite intr-un `requirements.txt`, deoarece proiectul nu foloseste Python ca runtime principal.

Dependentele aplicatiei sunt definite in:

- `package.json`
- `package-lock.json`

Pentru instalare:

```bash
npm install
```

Pentru rulare in dezvoltare:

```bash
npm run dev
```

Pentru build:

```bash
npm run build
```
